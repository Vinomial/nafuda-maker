個人情報について

入力した名前や背景画像は、どこにも送信・保存されません。

  • 名札の画像も PDF も、お使いのブラウザの中だけで作っています。サーバーにアップロードする処理はありません。
  • ページを閉じたり再読み込みしたりすると、入力内容は消えます。
  • ページの表示に使うフォント(Google Fonts)と PDF 作成ライブラリ(cdnjs)は外部から読み込みますが、入力内容は含まれません。
  • アクセス解析やトラッキングは使っていません。

ソースコードは GitHub で公開しています。

背景素材の探し方

上下に模様があり、中央が白っぽい横長〜正方形の画像がきれいに仕上がります。画像の上部と下部を切り出して、名札の上下の帯に使います。

  • イラストAC「抽象模様の背景」 このツールに合わせやすいおすすめ素材(無料会員登録が必要)
  • イラストAC で「背景 フレーム」を探す 日本語で探しやすい無料素材サイト
  • Pixabay で「背景 パターン」を探す 登録なしでダウンロードできる無料素材サイト
  • Canva で自分で作る テンプレートから背景を作って PNG で書き出せます

素材を使う前に、各サイトの利用規約(商用利用・クレジット表記・加工の可否など)を確認してください。
